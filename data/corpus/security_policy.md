# Security Policy

## 1. Password Requirements
- 12+ characters
- Mixed character types
- No reuse
- Change every 180 days

## 2. MFA
Required for VPN, email, production, and admin dashboards.

## 3. Device Security
Lock devices, enable encryption, report loss within 1 hour.

## 4. Network Security
VPN required offsite; no unauthorized scanning.

## 5. Badge Access
No sharing; report lost badges.

## 6. Incident Reporting
Report within 30 minutes.
